### Where the map's bytes are

* **the page**: `assets/map.js` 25.1 kB, `assets/rocks.js` 5.4 kB (the hero uses it too), and two requests for `data/ecosystem.json` 22.9 kB and `data/demos.json` 33.8 kB; the map's rules are in `site.css`.
* **the port**: the island's own `islands/map.js` 14.0 kB and `islands/map.css` 5.9 kB (inside `app.js`), the `places` JSON the program hands the island (in the HTML), and the **program's own code for the detail pane**: the `For` over the 24 projects and the four trail panels are unrolled at build time (`data.items` is closed, so each row is emitted as node-building code in `app.js`). Measured once by removing the four trail panels from a copy of the program (not regenerated by this script): `app.js` 273.4 kB to 225.0 kB, so **the four trail panels are about 48 kB of the script**; the 24 project panels are most of the rest of the difference with B2a's 87.3 kB script (by subtraction, not by a second removal: the program does not build with the `For` over projects removed, `list-empty`).
